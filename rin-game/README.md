# 凜界異聞錄｜守護靈結局版（v3 DEMO）

RiN凜 三週年紀念互動小品。跟著凜走完八章，最後找到屬於自己的守護靈，產出一張可分享的結果圖。
純 HTML／CSS／JS，**不用安裝任何東西，雙擊 index.html 就能玩**。橫式、直式手機都可以。

網址：https://rin93robin-ctrl.github.io/rin-game/rin-game/

> 公開時程：12/22 直播尾聲第一次公開連結，12/23 起正式宣傳（遊戲會劇透守護靈，所以不提前公開）。

---

## 遊戲流程

起名 → 旅途地圖 → 八章（對話 → 謎題 → 旅人抉擇 → 線索卡）→ 終章：守護靈揭曉 → 結果圖（下載／分享）→ 圖鑑、羅賓的信

- **沒有日期鎖**：完成上一章就能玩下一章，每章結束可以「直接前往下一章」。
- **旅人抉擇**：每章一題 3 選 1，不影響劇情，只影響守護靈。每個選項給一種守護靈 +2、另一種 +1；同分時從第八章往回看 +2、再看 +1。9 種守護靈出現機率約 9.6%～12.1%（以全部 6561 種選法模擬）。
- **進度顯示**：遊戲上方 8 格線索槽＋守護靈剪影（越拿越清楚）＋「守護靈感應度」；地圖上有旅途進度 %。
- **名字**：第一次開始時輸入（最多 8 字，留白＝馬凜薯），會出現在故事與結果圖上；設定裡可以改名。
- **第一章森林光影**：9 道光點對應 9 種守護靈，點了會出提示（直式手機會自動把整張森林完整顯示）。
- **結果圖**：貼文 4:5（1080×1350）、限動 9:16（1080×1920），可下載、手機可直接分享、可複製分享文字。
- **圖鑑**：重玩章節、改變選擇可以遇見其他守護靈；完成終章解鎖第 10 張「黑貓羅賓」。
- **黑貓密語**：設定裡輸入 10 篇目擊證詞拼出的「12/22三周年紀念直播見」，結果圖變成金色卡框。
- 保留：每章謎題、線索手帳、隱藏爪印、對話紀錄、文字速度與音量設定。

## 要改文字去哪裡

| 想改 | 檔案 |
|---|---|
| 每章台詞、謎題、旅人抉擇（`ask`）與計分 | `data/acts/act1.js`～`act8.js` |
| 守護靈名稱、關鍵字、籤詩、最合拍、森林提示 | `data/spirits.js` |
| 預設名字、不雅字詞清單、終章台詞、羅賓的信、分享文字、黑貓密語 | `data/settings.js` |
| 圖片與音樂路徑 | `data/assets.js` |

台詞裡寫 `{name}` 會換成玩家名字。旅人抉擇的格式：

```js
{"ask": "fairy", "q": "{name}，問題……", "options": [
  {"text": "選項文字", "score": {"dog": 2, "fox": 1}, "reply": "角色的回應"}
]}
```

**草稿提醒**：旅人抉擇的 24 句回應、終章台詞、羅賓的信、森林光影提示是我起草的，可自由修改；凜與各角色的定稿台詞沒有動。

## 更新後玩家會自動拿到新版

每次改完檔案，執行一次 `python3 tools/bump_version.py` 再上傳。網頁打開時會檢查 `version.txt`，版本不同就自動重新載入，不會卡在瀏覽器快取的舊版。

## 測試用網址參數

- `?reset=1` 清除進度（含名字）
- `?debug=1` 直接視為八章都完成，可以馬上測終章

進度存在玩家自己的瀏覽器，換裝置不會同步。

守護靈 ICON 為自繪 SVG。

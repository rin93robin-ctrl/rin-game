# 末日之夜：火鍋夜驚魂

像素風網頁遊戲：世界末日也不能放下眼前的火鍋。

- 遊玩網址（GitHub Pages）：https://rin93robin-ctrl.github.io/rin-game/hotpot/
- 檔案：`index.html`（遊戲本體）、`music.js`（8-bit BGM 合成）
- 純 HTML + JavaScript，不需要安裝任何東西；破關進度、排行榜存在玩家自己的瀏覽器

## 更新方式
改好 `index.html`／`music.js` 後推上 `main`，GitHub Pages 約 1～2 分鐘後自動更新。
玩家如果看到舊版，重新整理（或強制重新整理）即可。
